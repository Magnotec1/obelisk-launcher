## Instance Editor

Inspects instance components, version overrides, and installed content. You can toggle mods on or off, edit JVM arguments, view crash logs, or drag and drop `.jar` files directly into this window to install them.

<div align="center">
  <img src="screenshots/gallery/instanceeditor.png" alt="Instance Editor" width="850">
</div>

---

## Modrinth Browser

Integrated Modrinth search for mods, resource packs, shaders, and modpacks. Includes version selectors, dependency resolution, and changelog previews. CurseForge is not supported yet.

<div align="center">
  <img src="screenshots/gallery/modrinthbrowser.png" alt="Modrinth Browser" width="850">
</div>

---

## Playtime Analytics

Tracks play sessions and total hours across all instances. Records are stored separately from instance directories, so playtime data is retained even if you delete an instance.

<div align="center">
  <img src="screenshots/gallery/playtime.png" alt="Playtime Analytics" width="850">
</div>

## Account Management

Switch between multiple Microsoft accounts and offline testing profiles. Currently, Microsoft authentication requires entering an Azure Client ID in the setup wizard.
